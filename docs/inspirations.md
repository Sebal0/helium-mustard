# Inspirations and credits

## Helium

[Helium](https://github.com/imputnet/helium), by imput, inspired the neutral dark palette. Several neutral values were taken from its published palette, then combined with a custom mustard accent, softened text, and app-specific color roles.

Relevant upstream sources:

- [Helium color scheme](https://github.com/imputnet/helium/blob/main/patches/helium/ui/helium-color-scheme.patch)
- [Helium color mixers](https://github.com/imputnet/helium/blob/main/patches/helium/ui/helium-color-mixers.patch)
- [Helium licensing information](https://github.com/imputnet/helium#license)

Credit is to the visual palette and its published color definitions; this repository is not a browser fork.

## Dracula PyCharm

A **Dracula PyCharm** JSON theme credited to **YanivZalach** was supplied as the starting reference for the T3 Code theme structure. Its original author and title are acknowledged here. No original publication URL was provided, so none is guessed.

## Application formats

- [T3 Code](https://github.com/pingdotgg/t3code): its native version 1 JSON format supports a base appearance and an opposite-appearance variant.
- [Spotifast](https://github.com/crmne/spotifast): its native palette format uses a base mode and named hex colors.

## AI assistance

The collection was developed with AI assistance for research, palette proposals, color conversion, contrast calculations, documentation, and packaging. Sebastian Sroka selected the direction and refined the result through successive feedback.

The color choices are not a clinically validated treatment for visual fatigue. Contrast checks are numerical checks of specified color pairs, not a complete accessibility audit of either application.
